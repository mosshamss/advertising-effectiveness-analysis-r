# Dataset setup

The CSV file was not included with the supplied project files. To run the R script, obtain the public Advertising dataset at:

https://www.kaggle.com/datasets/ashydv/advertising-dataset?resource=download

Place the dataset in the repository **root** and name it `advertising.csv`.

The original script expects these exact, case-sensitive column names: `TV`, `Radio`, `Newspaper`, `Sales`.

Some dataset variants use lowercase headers. If yours does, rename the headers in a local copy of the CSV to match the script before running. Other extra columns can be ignored.

No data have been fabricated or included in this portfolio package.
